## 2. 히어로

- 제목(제품명, 1줄): **최애를 풀어놨습니다**
- 한 줄 설명 — 3안

| 안 | 문구 | 비고 |
|---|---|---|
| A (추천) | 내 최애 사진이 화면 위를 돌아다녀요. 일하기 싫은 날엔 퇴근 알림도 챙겨 줘요. | 덕후(사진)와 직장인(퇴근)을 한 문장씩 담았다. 2줄 이내. |
| B | 좋아하는 사진을 내 화면 위 버디로 만들어 보세요. 지친 날엔 퇴근 알림이 기다려요. | 조금 더 권유형. |
| C | 최애도 반려동물도 내 화면 위에서 놀아요. 퇴근 시간엔 이모지가 팡 올라와요. | 가장 귀여운 톤. 퇴근 알림 연출이 앱 동작과 같아야 하니 디자인 확인 후 사용. |

추천 이유: A는 약속이 사실(사진 올리기, 퇴근 알림)과 정확히 맞고 "버디" 같은 앱 용어 없이도 읽힌다.

- 버튼 1 (OS에 따라 채운 버튼/회색): `Windows용 다운로드 v1.0.9`
- 버튼 2: `macOS용 다운로드 v1.0.8`
- 버튼 아래 작은 글씨(macOS): Apple Silicon(M1 이후) 전용
- 모바일 접속 시 한 줄: 컴퓨터에서 받아 주세요
- 신뢰 문구 2줄:
  1. 앱 안에는 광고가 없어요.
  2. 내 사진과 설정은 내 컴퓨터에만 저장돼요.
- 스테이지(버디 걷기) aria-label: 고양이 버디가 화면 위를 천천히 왔다 갔다 걷는 모습
- 스테이지 버디 버튼 aria-label: 버디 누르기. 폴짝 뛰어요
- 버튼 aria-label(다운로드는 label 그대로 읽히므로 별도 불필요)

### 코드 반영 문구 (히어로 스테이지, 2026-10-21)

- 스테이지 안내 캡션 (`Hero.tsx`, 움직임 줄이기 켜면 캡션 자체를 숨김): **버디를 눌러 보세요. 폴짝 뛰어요.**
  - 이유: 눌렀을 때 일어나는 일을 한 마디 덧붙여 눌러 볼 이유를 준다. 점프는 디자인 지시서 5장(120ms 점프 1회)과 같다.
- 스테이지 aria-label(움직일 때): 고양이 버디가 화면 위를 천천히 왔다 갔다 걷는 모습 (위 문구 그대로, 코드와 같음)
- 스테이지 aria-label(움직임 줄이기): 가만히 서 있는 고양이 버디 (코드에만 있던 문구를 문서에 올림)
- 스테이지 버디 버튼 aria-label: 버디 누르기. 폴짝 뛰어요 (위 문구 그대로, 코드와 같음)
- 비교 결과: 코드와 문서가 같아서 문서 기준으로 맞출 변경은 없다. 다만 움직임 줄이기 상태에서는 버튼이 `disabled`라 읽히지 않는다. 그 상태의 안내는 스테이지 aria-label("가만히 서 있는 고양이 버디")이 맡는다.

삭제할 기존 문구: "100% 로컬 작동", "서버 통신 없는", "설치 없이 바로 실행(간편 설치)" 칩, "별가루 가득한 힐링", "WORK HATE CLUB GOAT", "ALL FEATURES FREE FOREVER", "무료 베타 단계", "스마트 스크린 가이드 완벽 제공".

## 3. 앱 화면

### 판단: "곧 나올 새 디자인"으로 명시해서 쓴다

이유: 설명 3줄(칩으로 바꿔요 / 카드에서 바로 / 저장 버튼 없이 즉시 적용)은 새 디자인(v1.1.0)에만 있는 동작이다. v1.0.9에는 설정창 저장·확인 방식이 있었다(v1.0.4 노트 근거). 그래서 지금 받는 앱과 다르다는 사실을 첫 줄에서 밝힌다. 버전 무관 설명으로 쓰면 3줄 중 2줄이 성립하지 않는다.
v1.1.0 배포 후에는 제목의 "곧 나올"과 안내 문장만 지우면 된다(맨 아래 "배포 후 교체표" 참고).

- 섹션 제목: **곧 나올 새 설정창을 미리 봐요**
- 안내(캡션 첫 줄, 보조색): 아래 화면은 새 디자인(v1.1.0)이에요. 지금 받는 v1.0.9와는 설정창 모양이 달라요.
- 설명 3줄(소제목 + 한 문장):
  1. **칩으로 바꿔요** — 모드, 크기, 활동 구역, 움직임 속도를 칩 하나씩 눌러서 골라요.
  2. **카드에서 바로** — 점심·퇴근 알림 시간과 미리 알림을 카드 안에서 바로 바꿔요.
  3. **저장 버튼 없이 즉시 적용** — 값을 바꾸면 버디에 바로 반영돼요.
- 스크린샷 캡션 2개:
  - 사진 자르기: 내 사진은 원하는 모양으로 잘라서 올려요. 자르기는 지금 버전에도 있어요.
  - 퇴근 알림: 정한 시각에 퇴근 알림이 화면에 떠요. 알림은 지금 버전에도 있어요.
- 이미지 alt (5장, 라이트/다크는 같은 alt):
  - 홈(라이트/다크): 최애를 풀어놨습니다 설정창 홈 화면. 오른쪽에 버디 미리보기, 왼쪽에 모드·크기·활동 구역 같은 설정 칩, 아래에 점심 알림과 퇴근 알림 카드가 있어요.
  - 사진 자르기: 올린 사진을 원형 틀에 맞춰 자르는 창. 확대와 위치 조절, 원형·사각형 선택이 보여요.
  - 퇴근 알림: 화면 가운데에 버디와 퇴근 시각이 적힌 카드가 뜨고 주변에 이모지가 올라오는 모습.
  - 미리 알림 토스트: 고양이 버디 위에 종 아이콘과 "퇴근 5분 전이에요!"라고 적힌 작은 알림이 떠 있는 모습. (`public/screens/toast.webp`를 직접 보고 확인. 캡처에 실제로 뜬 문구 그대로이며 느낌표도 앱 문구라 그대로 둠)

### 코드 반영 문구 (앱 화면 토스트, 2026-10-21)

- 토스트 캡션 (`AppScreens.tsx`): **퇴근 몇 분 전에 버디 위로 작은 알림이 먼저 떠요. 미리 알림은 지금 버전에도 있어요.**
  - 근거: v1.0.9 공식 노트에 "점심·퇴근 미리 알림(1~30분 전)" 오류 수정이 있어 현재 버전에 있는 기능이다. 캡처 속 알림은 말풍선 모양이 아니라 종 아이콘이 붙은 알림 칸이라 "말풍선" 대신 "작은 알림"으로 썼다. 분 수는 사용자가 정하는 값이라 캡션에는 "몇 분 전"으로만 쓴다.
- 토스트 이미지 alt: 고양이 버디 위에 종 아이콘과 "퇴근 5분 전이에요!"라고 적힌 작은 알림이 떠 있는 모습

## 4. 기능

섹션 제목: **내 사진이 버디가 되고, 하루가 조금 가벼워져요** (2줄 이하)
짧은 대안: 사진 한 장이면 버디가 돼요

### 4-1. 큰 블록 — 내 사진이 버디가 돼요
- 소제목: **내 사진이 버디가 돼요**
- 본문: 최애 사진이나 반려동물 사진을 올리면 그대로 내 화면을 돌아다니는 버디가 돼요. 올릴 때 원형이나 사각형으로 자를 수 있고, 잘린 모양 그대로 화면에 나와요.
- 사진 준비 팁(소제목: 사진 준비 팁):
  - 파일 형식은 PNG를 권해요.
  - 크기는 200~300px 정도가 알맞아요.
  - 용량은 5MB 이하여야 해요.
  - 배경을 지운 PNG가 가장 자연스러워요. 배경 지우기는 [remove.bg](https://www.remove.bg)에서 할 수 있어요.
- 링크 텍스트: remove.bg에서 배경 지우기 (새 탭, `rel="noopener noreferrer"`, aria-label: remove.bg 새 창에서 열기)
- 이미지 alt(사진→버디 예시를 쓸 경우): 반려동물 사진을 동그랗게 잘라 만든 버디가 화면 위에 올라가 있는 모습 `[확인 필요: 예시 이미지를 쓸지, 실제 사용 허락된 사진인지]`

### 4-2. 중간 블록 — 동물 8종
- 소제목: **동물 친구 8종**
- 본문: 사진이 없어도 괜찮아요. 고양이, 강아지, 토끼, 여우, 햄스터, 곰, 펭귄, 오리 중에서 골라요.
- 각 동물 이미지 alt: 고양이 버디 / 강아지 버디 / 토끼 버디 / 여우 버디 / 햄스터 버디 / 곰 버디 / 펭귄 버디 / 오리 버디

### 4-3. 줄 목록 (제목 + 한 줄)
1. **활동 모드 3단계** — Chill은 거의 안 움직이고 조용히 옆에 있어요. Buddy는 가끔 움직이고 말풍선도 띄워요. Chaos는 빠르게 날아다니고 이모지도 자주 나와요.
2. **4분할 활동 구역** — 화면을 네 칸으로 나눠 좌상단·우상단·좌하단·우하단 중 한 곳에서만 돌아다니게 할 수 있어요. 모니터가 둘이면 어느 모니터에서 움직일지도 골라요.
3. **움직임 속도** — 느긋하게부터 아주 빠르게까지 속도를 골라요.
4. **야르 타임** — 정해 둔 간격마다 이모지가 화면에 쏟아져요. 기본은 꺼져 있고, 켜면 30분·1시간·1시간 30분·2시간·3시간 중에서 골라요.
5. **졸림 방지** — 졸린 오후에 이모지가 불쑥 나타나 잠을 깨워 줘요. 나타나는 주기는 직접 정해요.
6. **말풍선 문구** — 버디가 시간대에 맞춰 한마디씩 해요. 매달 25일엔 월급 문구, 금요일엔 불금 문구가 나와요.

추가 제안 줄(직장인 겨냥, 선택): **점심·퇴근 알림** — 정한 시각에 화면 가득 알려 줘요. 몇 분 전에 미리 알려 주는 알림도 있어요.
참고: 말풍선 문구를 사용자가 앱에 넣는 기능은 없으므로 "커스텀 대사", "문구 주입" 표현은 쓰지 않는다.

삭제할 기존 문구: "데스크탑 최상단 고정 … 회피 로직", "정밀한 보폭 조절", "말풍선 주입", "메시지 발송", "동물 가문", "든든한 기술력", "킹받는 회사 잔소리".

## 6. 설치 안내

- 섹션 제목: **설치는 금방 끝나요**
- 탭(세그먼트): Windows / macOS

### Windows (3단계)
1. **받기** — 위의 Windows용 다운로드 버튼으로 파일(.exe)을 받아요. (링크 텍스트: Windows용 파일 받기 v1.0.9)
2. **실행** — 받은 파일을 더블클릭해요. 따로 설치하지 않고 바로 실행돼요.3. **SmartScreen 안내** — "Windows의 PC 보호" 창이 뜨면 **추가 정보**를 누른 뒤 **실행**을 눌러요. 처음 받는 앱에는 이 창이 뜰 수 있어요.

## 8. FAQ

섹션 제목: **자주 묻는 질문**
(전체 12문. 위에서부터 설치 전 걱정 → 사진 → 사용 → 문제 해결 순서)

**Q1. 무료인가요?**
네, 무료로 받아서 쓸 수 있어요. 앱 안에는 광고가 없어요.

**Q2. 내 강아지나 최애 사진도 버디로 쓸 수 있나요?**
네, 쓸 수 있어요. 사진을 올리고 원형이나 사각형으로 자르면 버디가 돼요. PNG, 200~300px, 5MB 이하를 권해요. 배경을 지운 PNG가 가장 자연스러워요.

**Q3. 올린 사진은 어디에 저장되나요?**
내 사진과 설정은 내 컴퓨터에만 저장돼요.

**Q4. 회사 컴퓨터에 깔아도 되나요?**
회사마다 보안 규칙이 달라서 먼저 확인해 보시길 권해요. 이 앱은 개인이 만든 앱이라 처음 실행할 때 SmartScreen 안내가 뜰 수 있어요. 내 사진과 설정은 내 컴퓨터에만 저장돼요. 개발자는 사용자의 정보를 받지 않아요.

**Q5. 컴퓨터가 느려지지 않나요?**
움직임을 30fps로 제한해서 사양이 낮은 PC에서 버벅이던 것을 줄였어요. 그래도 느려진다 싶으면 Chill 모드로 바꾸거나 버디 크기를 작게 해 보세요.

**Q6. Windows에서 보안 경고가 떠요. 괜찮은가요?**
처음 받는 앱에는 "Windows의 PC 보호" 창이 뜰 수 있어요. 창에서 **추가 정보**를 누른 뒤 **실행**을 누르면 돼요. 파일은 이 사이트의 다운로드 버튼으로 받은 것만 실행해 주세요.

**Q7. macOS에서 "확인되지 않은 개발자"라고 열리지 않아요.**
시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 눌러 주세요.
**Q8. 인텔 맥에서도 되나요?**
인텔 맥은 아직 지원하지 않아요. Apple Silicon(M1 이후) 맥에서만 쓸 수 있어요.

**Q9. 모드는 뭐가 다른가요?**
Chill은 거의 움직이지 않고 조용히 옆에 있어요. Buddy는 기본 설정이고, 가끔 움직이면서 말풍선도 띄워요. Chaos는 빠르게 날아다니고 이모지와 야르 타임도 자주 나와요.

**Q10. 버디가 화면에서 사라졌어요.**
트레이 아이콘을 우클릭해서 "버디 부르기"를 눌러 보세요. 설정창의 표시 설정에도 같은 버튼이 있어요.

**Q11. 버디를 숨기거나 앱을 끌 수 있나요?**
트레이 아이콘을 우클릭하면 설정 열기, 버디 부르기, 버디 보이기, 버디 숨기기, 앱 종료를 고를 수 있어요. 버디를 우클릭해도 설정창이 열려요.

lala525.404@gmail.com 으로 메일을 보내 주세요. 하나하나 읽어 볼게요. (mailto 링크, 제목 기본값: `[최애를 풀어놨습니다] 문의`)

- 앱 다운로드: 다운로드 버튼을 누르면 GitHub Releases에서 파일을 받아요. 이 다운로드에는 GitHub의 개인정보처리방침이 적용돼요.

**앱 안의 데이터** (기존 highlight 박스 문장을 교체. 이모지 체크 아이콘 삭제)
앱 안에는 광고가 없어요. 앱에서 정한 설정값과 올린 사진은 내 컴퓨터에만 저장돼요. 개발자는 사용자의 정보를 받지 않아요.
예: 버디 종류, 모드, 크기, 활동 구역, 알림 시각, 올린 사진이 여기에 해당해요.
(선택, 사실 공개용) 앱은 버디 이미지(Twemoji)를 외부 이미지 서비스(jsDelivr)에서 불러와요. 이때 해당 서비스에 접속 기록이 남을 수 있어요. "앱이 외부와 전혀 통신하지 않는다"는 표현은 쓰지 않는다.

**Google Analytics**
이 사이트는 방문 현황을 파악하려고 Google LLC의 웹 분석 서비스인 Google Analytics를 써요. Google Analytics는 쿠키를 사용해 방문자가 사이트를 어떻게 쓰는지에 대한 통계 정보를 모아요.
- 수집하는 것: 방문 페이지, 머문 시간, 브라우저·운영체제·기기 종류, 대략적인 접속 지역, 접속 경로 같은 이용 통계예요.
- 쓰는 곳: 어떤 내용이 도움이 되는지 살펴 사이트를 고치는 데만 써요.
- 보관과 처리: 수집된 정보는 Google이 정한 기간과 방식에 따라 Google 서버에서 처리돼요. 자세한 내용은 [Google이 데이터를 사용하는 방식](https://policies.google.com/technologies/partner-sites)을 확인해 주세요.
- 거부하는 방법: 아래 방법 중 하나를 쓰면 통계 수집을 막을 수 있어요. 막아도 사이트와 앱은 똑같이 쓸 수 있어요.
  - 브라우저 설정에서 쿠키를 차단하거나 삭제해요.
  - [Google Analytics 차단 브라우저 부가기능](https://tools.google.com/dlpage/gaoptout)을 설치해요.

`[확인 필요: GA4 "개인 식별 정보 미수집", "쿠키 사용"은 일반적인 GA 안내 수준으로 썼다. 사이트에 광고 개인 최적화(Google signals) 기능을 켜 두었는지 GA 설정 확인]`

### 11-4. 보관용 AdSense 원문 (HTML 주석으로 넣을 것)

권장 위치: 새 "Google Analytics" 섹션 바로 위에 `<!-- ... -->` 한 덩어리로 붙인다. 아래 원문 안에는 `--`가 없어서 주석이 중간에 끊기지 않는다. 앞에 이유 한 줄을 같이 넣는다.

(1) "수집하는 정보" 목록의 항목
        <li><strong>광고 관련 데이터:</strong> Google AdSense를 통한 맞춤형 광고 제공을 위해 쿠키가 사용될 수 있습니다.</li>

(2) 별도 섹션 전체

      <h2>Google AdSense 및 광고 쿠키</h2>
      <p>본 랜딩페이지는 Google AdSense를 통해 광고를 게재합니다. Google은 광고 쿠키를 사용하여 사용자의 이전 방문 기록을 기반으로 맞춤 광고를 표시할 수 있습니다.</p>
      <ul>
        <li>Google의 광고 쿠키 사용에 대한 자세한 내용은 <a href="https://policies.google.com/privacy" target="_blank" rel="noopener" style="color:#7c3aed;">Google 개인정보처리방침</a>을 참고하세요.</li>
        <li>맞춤 광고를 원하지 않으시면 <a href="https://www.google.com/settings/ads" target="_blank" rel="noopener" style="color:#7c3aed;">Google 광고 설정</a>에서 비활성화할 수 있습니다.</li>
      </ul>
    </div>

(3) meta description 원문
  <meta name="description" content="최애를 풀어놨다 앱의 개인정보처리방침입니다. 수집 정보, 쿠키, 광고 정책 등을 안내합니다." />
