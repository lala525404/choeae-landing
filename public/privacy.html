수집하는 정보

최애를 풀어놨습니다(이하 "서비스")는 사이트 운영과 개선을 위해 아래 정보를 수집해요.

  • 방문 통계: 방문한 페이지, 머문 시간, 브라우저 종류, 운영체제, 기기 종류, 접속 지역(국가·도시 수준), 접속 경로를 Google Analytics로 수집해요. 이름이나 이메일처럼 개인을 직접 알아볼 수 있는 정보는 수집하지 않아요.
  • 앱 다운로드: 다운로드 버튼을 누르면 GitHub Releases에서 파일을 받아요. 이 다운로드에는 GitHub의 개인정보처리방침이 적용돼요.

앱 안의 데이터

앱 안에는 광고가 없어요. 앱에서 정한 설정값과 올린 사진은 내 컴퓨터에만 저장돼요. 개발자는 사용자의 정보를 받지 않아요.

예: 버디 종류, 모드, 크기, 활동 구역, 알림 시각, 올린 사진이 여기에 해당해요.

일부 이전 버전(v1.1.0 미만)은 버디 이미지(Twemoji)를 외부 이미지 서비스(jsDelivr)에서 불러와요. 이때 해당 서비스에 접속 기록이 남을 수 있어요. v1.1.0부터는 이미지가 앱에 포함되어 있어서 외부에서 불러오지 않아요.

업데이트 확인: 앱은 새 버전이 있는지 확인하려고 GitHub의 릴리스 정보에 접속해요. 앱을 시작하고 약 10초 뒤에 한 번, 이후 6시간마다 자동으로 확인하고, 설정창의 "업데이트 확인" 버튼을 누를 때도 접속해요. 이때 IP 주소와 일반적인 요청 정보가 GitHub의 일반 웹 접속 기록으로 처리될 수 있어요. 알람, 사진, 펫 설정 같은 사용자 데이터는 업데이트 확인으로 전송되지 않아요. 새 버전이 있으면 알림 창이 뜨고, 새 버전 다운로드는 그 창에서 "지금 업데이트" 버튼을 눌렀을 때만 시작돼요. "나중에"를 누르거나 창을 닫으면 받지 않아요.

날씨 안부(v1.5.0부터): 앱 설정에서 동네를 고르고 안내 대화상자의 [좋아요]를 누르면, 말풍선에 날씨 안부를 보여주려고 선택한 동네가 속한 시·군·구의 대표 좌표(소수점 2자리까지)를 날씨 서비스 Open-Meteo로 전송해요. 동의하기 전에는 아무것도 전송하지 않아요. 이름, 사진, 알람, 펫 설정 같은 다른 정보는 전송하지 않아요. 설정에서 [지우기]를 누르면 동네가 삭제되고 동의도 철회되며, 그때부터 날씨 요청을 보내지 않아요. 날씨 요청은 앱이 내 컴퓨터에서 Open-Meteo로 직접 보내고 개발자의 서버를 거치지 않아요. 이때 좌표와 IP 주소 같은 일반적인 요청 정보가 Open-Meteo 서버 로그에 남을 수 있어요. 날씨 데이터 출처는 Open-Meteo(CC BY 4.0)예요.

알람 대화(v1.6.0부터): 우클릭 퀵 메뉴의 [대화하기]에 입력한 문장은 앱이 내 컴퓨터 안에서 정해진 규칙으로만 해석해요. 이 문장은 네트워크로 전송되지 않고, 외부 서비스나 AI에도 보내지 않으며, 저장하지 않아요. 확인 카드에서 [만들기]를 눌러 만든 알람만 다른 알람과 똑같이 내 컴퓨터에 저장돼요.

Google Analytics

이 사이트는 방문 현황을 파악하려고 Google LLC의 웹 분석 서비스인 Google Analytics를 써요. Google Analytics는 쿠키를 사용해 방문자가 사이트를 어떻게 쓰는지에 대한 통계 정보를 모아요.

  • 수집하는 것: 방문 페이지, 머문 시간, 브라우저·운영체제·기기 종류, 대략적인 접속 지역(도시 수준), 접속 경로 같은 이용 통계예요.
  • 쓰는 곳: 어떤 내용이 도움이 되는지 살펴 사이트를 고치는 데만 써요.
  • 보관과 처리: 수집된 정보는 Google이 정한 기간과 방식에 따라 Google 서버에서 처리돼요. 자세한 내용은 Google이 데이터를 사용하는 방식을 확인해 주세요.
  • 거부하는 방법: 아래 방법 중 하나를 쓰면 통계 수집을 막을 수 있어요. 막아도 사이트와 앱은 똑같이 쓸 수 있어요.
    • 브라우저 설정에서 쿠키를 차단하거나 삭제해요.
    • Google Analytics 차단 브라우저 부가기능을 설치해요.

제3자 서비스

서비스는 다음 외부 서비스와 연동돼요.

  • GitHub Releases: 앱 다운로드 파일 배포
  • Open-Meteo: 앱의 날씨 안부에 쓰는 날씨 데이터(선택한 동네의 대표 좌표를 동의한 뒤에만 전송, 데이터 출처 Open-Meteo CC BY 4.0)
  • Buy Me a Coffee: 개발자 후원 서비스

이 사이트는 Vercel에서 호스팅되며, 접속 시 IP 주소 등 접속 기록이 호스팅 제공자의 서버 로그에 기록될 수 있습니다.

이들 외부 서비스에서의 개인정보 처리는 해당 서비스의 개인정보처리방침을 따라요.
