어떤 앱인가요?

최애를 풀어놨습니다는 좋아하는 캐릭터나 반려동물 사진을 내 화면 위로 풀어놓는 데스크탑 버디 앱이에요.

컴퓨터로 작업하는 동안 화면 한편에서 버디가 걷고, 낮잠을 자고, 말풍선으로 한마디씩 해요. 내 사진을 올리면 세상에 하나뿐인 나만의 버디를 만들 수 있어요. 점심·퇴근 알림도 챙겨 줘요.

Windows와 macOS(Apple Silicon, M1 이후)에서 쓸 수 있고, 무료로 받아서 쓸 수 있어요. 앱 안에는 광고가 없어요.

  • Windows (x64)
  • macOS (Apple Silicon 전용)
  • 무료

주요 기능

  • 활동 모드 3단계: Chill, Buddy, Chaos 모드로 버디의 활동량을 골라요.
  • 내 사진 버디: 원하는 사진을 올려 원형이나 사각형으로 잘라 버디로 써요.
  • 크기 조절: 소·중·대 중에서 화면에 맞는 크기를 골라요.
  • 활동 구역: 화면을 네 칸으로 나눠 버디가 돌아다닐 곳을 정해요.
  • 낮잠 모션: 일하다 슬쩍 잠드는 낮잠 모션이 있어요.
  • 트레이 제어: 트레이 아이콘으로 버디를 숨기거나 설정을 열어요.

어떻게 사용하나요?

  1. 다운로드: 첫 화면에서 운영체제에 맞는 파일을 받아요. (Windows: .exe, macOS: .dmg)
  2. 실행: Windows는 받은 파일을 실행하고, macOS는 받은 파일을 열어 앱을 응용 프로그램 폴더로 끌어 놓아요.
  3. 버디 고르기: 설정창에서 동물 버디를 고르거나 내 사진을 올려요.
  4. 모드 고르기: Chill, Buddy, Chaos 중 원하는 모드를 골라요.

내 사진 준비하는 법

배경을 지운 PNG가 가장 자연스러워요. 배경 지우기는 remove.bg 같은 서비스나 사진 편집 프로그램으로 할 수 있어요.

  • 파일 형식은 PNG를 권해요.
  • 크기는 200~300px 정도가 알맞아요.
  • 용량은 5MB 이하여야 해요.
